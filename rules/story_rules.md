# ストーリー構成のルール（試験中・まだ毎朝の自動作成には使わない）

2026-11-02 作成。見本 drafts/story-sample/ を本人が読んで、正式に採用するか決める。
採用が決まったら、rules/writing_rules.md の「記事の構成」をこのファイルの「記事の構成（ストーリー版）」に置きかえ、CLAUDE.md 手順2の読むファイルに rules/story_rules.md を加える。
それまでは今の rules/writing_rules.md の構成で書く。

文体（やさしい話し言葉・読点少なめ・年代を書かない・AIっぽい言い回しを使わない・商品は名前だけ）は rules/writing_rules.md のまま。このファイルは「話の流れ」だけを決める。

## いちばん大切な考え方
読者の気持ちが「下がる → 上がる → 下がる → 上がる」と動く記事にする。
悩みを説明して解決方法を並べるだけの記事にしない。

## 話の流れ（この順番を基本にする）
1. **悩み**：読者が「あ、これ私のことだ」と思う毎日の場面から始める（例：朝巻いたのに昼にはカールが取れている）
2. **解決のヒント**：どうすれば良くなるかを分かりやすく伝える（気持ちが上がる）
3. **うまくいかない理由**：その方法だけでは解決しないこともある。よくある失敗や見落としを伝える（少し下がる）
4. **もうひとつのコツ**：うまくいかなかった理由を説明して、さらに役立つ方法を伝える（もう一度上がる）。商品はここか6で、解決方法のひとつとして自然に出す
5. **注意点・苦手なこと**：その方法や商品にも苦手なことがある。良いことばかり書かず正確に伝える
6. **解決への道筋**：無理なく続けられる方法・取り入れやすい工夫
7. **具体的な未来**：悩みが少しラクになったら、毎日の生活のどんな場面が変わるかを描く

- 7つを見出しにそのまま並べなくてよい。「悩み」「解決」「失敗」「コツ」などの言葉を見出しにしない
- 2つの段階を1つの見出しにまとめたり、見出しの数を変えたりしてよい（目安は4〜6個の h3 ＋よくある質問＋まとめ）
- 見出しは読者が気になる問いや場面にする（例：「温度を上げても取れるのはなぜ？」）

## 最後の「具体的な未来」の書き方
- 抽象的な言葉は使わない：「ステキになります」「自分らしくなれます」「毎日が輝きます」「自信が持てます」など
- 読者が頭の中で場面を思い浮かべられる、生活の一場面を2〜3個描く
  - 朝の髪のセットがラクになって、コーヒーを飲む時間ができる
  - 何度も髪を直さなくて済み、仕事中も髪が気になりにくくなる
  - 雨の日でも髪型を気にしすぎず出かけられる
  - 家を出る前にひと息つける
  - 友達との写真も楽しみやすくなる
  - 美容室から帰ったあとも、自分で形を整えやすくなる
- 成果を約束しない：「30分短縮」「必ず褒められる」「上司から好かれる」など、証明できない結果は書かない。「〜しやすくなる」「〜が減る」くらいの言い方にする

## ストーリーの自然さ
- わざと大きな問題を作らない。不安をあおらない。下げる場面のあとには必ず上げる場面を続け、不安なまま終わらせない
- 体験していないことを事実のように書かない：「やってみた」「お客様に言われた」「〜という方がいました」は書かない
- 読者が経験しそうな場面を「〜こと、ありませんか？」「たとえば〜」と例として描くのはOK
- 説明が続きすぎない。説明が3段落続いたら、場面や問いかけをはさむ

## 商品
- これまでどおり1記事1商品以上（基本1つ、多くて2つ）。商品名は「商品名」部品（ブルーの囲み）に名前だけ。リンクは入れない
- 解決方法のひとつとして話の流れの中で出す（4か6）。メリットだけでなく、必要なら注意点も5で伝える

## 記事の構成（ストーリー版）
1. プロフィール・提案スタイル（今と同じ）
2. 大見出し（タイトルと同じ）
3. 導入：「こんなご相談をよくいただきます。」＋吹き出し → 毎日の場面（悩み）→ 心の声（黄色枠）
4. 小見出し h3 を4〜6個。上の「話の流れ」2〜7をこの中で進める
5. よくある質問（2〜4問。本文と同じ質問は入れない）
6. まとめ（3つのやることのリスト → 具体的な未来をひと言 →「是非参考にしてみてください！」）
7. LINE・店舗・Instagram（今と同じ）

## 自動チェック
今の scripts/check_post.py のまま使える（構成の順番まではチェックしない）。
書き終えたら「気持ちが下がる → 上がる → 下がる → 上がる」になっているか、最後の未来が具体的な場面になっているかを自分で読み直して確かめる。
