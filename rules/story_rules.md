rules/writing_rules.md の「記事の構成」もこのファイルに合わせてある。

文体（やさしい話し言葉・読点少なめ・年代を書かない・AIっぽい言い回しを使わない・商品は名前だけ）は rules/writing_rules.md のまま。このファイルは「話の流れ」だけを決める。

## いちばん大切な考え方
読者の気持ちが「下がる → 上がる → 下がる → 上がる」と動く記事にする。
悩みを説明して解決方法を並べるだけの記事にしない。

## 話の流れ（この順番を基本にする。2026-11-02 改訂）
1. **悩み**：読者が「あ、これ私のことだ」と思う毎日の場面から始める（例：朝巻いたのに昼にはカールが取れている）
2. **解決のヒント**：どうすれば良くなるかを分かりやすく伝える（気持ちが上がる）
3. **うまくいかない理由**：その方法だけでは解決しないこともある。よくある失敗や見落としを伝える（少し下がる）
4. **もうひとつのコツ**：うまくいかなかった理由を説明して、さらに役立つ方法を伝える（もう一度上がる）。商品はここで、解決方法のひとつとして自然に出すことが多い。続けやすい工夫もここか5に入れる
5. **注意点**：その方法や商品にも苦手なことがある。良いことばかり書かず正確に伝える
6. **具体的な未来**：悩みが少しラクになったら、毎日の生活のどんな場面が変わるかを描く（いちばん大切にする）

- 「下げる → 上げる → 下げる → 上げる」の考え方は守る。ただし毎回同じ流れ・同じ数の見出しにしない
  - 記事のテーマに合わせて自然に変える。段階を1つの見出しにまとめる、順番を少し入れかえる、下げる場面を短い一文にする、など
  - 書く前に直近の記事の見出しの数と並びを見て、同じ形が続かないようにする
- 「悩み」「解決」「失敗」「コツ」「注意点」「未来」などの言葉を見出しにしない
- 見出しは読者が気になる問いや場面にする（例：「温度を上げても取れるのはなぜ？」）。数はテーマに合わせて決める（3〜6個くらい）。毎回同じ数にしない

## 最後の「具体的な未来」の書き方
- 抽象的な言葉は使わない：「ステキになります」「自分らしくなれます」「毎日が輝きます」「自信が持てます」など
- 場面の数は決めない。1〜2場面でも十分。大切なのは数ではなく、読者が自分の生活を自然に想像できること
  - 朝・昼・夜などをそろえるために場面を無理に増やさない。テーマにいちばん近い場面をていねいに描く
  - 未来は独立した見出しにしてもよいし、最後の見出しやまとめの中で短く描いてもよい
- 「悩みがゼロになる」ではなく「悩みが少しラクになった日」の場面として描く。「〜日が増えてくると」「〜しやすくなると」のように、変化はゆるやかに書く
- 場面の例（この中から全部使う必要はない。テーマに合うものを1〜2個）
  - 朝の髪のセットがラクになって、コーヒーを飲む時間ができる
  - 何度も髪を直さなくて済み、仕事中も髪が気になりにくくなる
  - 雨の日でも髪型を気にしすぎず出かけられる
  - 家を出る前にひと息つける
  - 友達との写真も楽しみやすくなる
  - 美容室から帰ったあとも、自分で形を整えやすくなる
- 成果を約束しない：「30分短縮」「必ず褒められる」「上司から好かれる」など、証明できない結果は書かない。「〜しやすくなる」「〜が減る」くらいの言い方にする
- 未来の場面も架空の体験談にしない（「〜という方もいます」「こう言われました」は書かない）。読者が経験しそうな場面を例として描く

## ストーリーの自然さ
- わざと大きな問題を作らない。不安をあおらない。下げる場面のあとには必ず上げる場面を続け、不安なまま終わらせない
- 体験していないことを事実のように書かない：「やってみた」「お客様に言われた」「〜という方がいました」は書かない
- 読者が経験しそうな場面を「〜こと、ありませんか？」「たとえば〜」と例として描くのはOK
- 説明が続きすぎない。説明が3段落続いたら、場面や問いかけをはさむ
- 話を無理に盛り上げない。「落とし穴」「衝撃」「実は危険」のような大げさな言い方はしない。下げる場面も「〜しがちなんです」くらいのやわらかさで
- 数字や回数の決まりより、自然な文章を優先する。「かもしれません」も自然なら使ってよい。ただ同じ言い方が続かないよう、「〜しやすくなります」「〜ですよね」「〜こともあります」などと混ぜる

## 商品
- これまでどおり1記事1商品以上（基本1つ、多くて2つ）。商品名は「商品名」部品（ブルーの囲み）に名前だけ。リンクは入れない
- 解決方法のひとつとして話の流れの中で出す（主に4の「もうひとつのコツ」）。メリットだけでなく、必要なら注意点も5で伝える

## 記事の構成（ストーリー版）
1. プロフィール・提案スタイル（今と同じ）
2. 大見出し（タイトルと同じ）
3. 導入：「こんなご相談をよくいただきます。」＋吹き出し → 毎日の場面（悩み）→ 心の声（黄色枠）
4. 小見出し h3 をテーマに合わせて3〜6個くらい。上の「話の流れ」2〜6をこの中で進める（数と並びは毎回変える）
5. よくある質問（2〜4問。本文と同じ質問は入れない）
6. まとめ（3つのやることのリスト → 今夜・明日の朝にできることをひと言 →「是非参考にしてみてください！」。未来の章をくり返さない）
7. LINE・店舗・Instagram（今と同じ）

## 長さ
- 文字数の下限は決めない。1,800字くらいでも内容が十分ならよく、必要なら3,000字以上でもよい
- 字数を増やすために説明・Q&A・場面を足さない
