# 文章のルール

参考記事6本の分析（rules/style_analysis.md）を反映。語り口は samples/articles/ 02〜06 を見本にする。
rules/style_analysis.md の「決まった言い回し」は参考。合わないときは使わず、下の「文体の基準」を優先する。

## 読者
- 30〜50代の女性。髪や頭皮の具体的な悩みを検索してたどり着いた人
- 美容室でお客様に話すように、やさしく具体的に。専門用語には短い説明を付ける

## 文体の基準（2026-10-29 改訂。以前の「語り口」「話し言葉のリズム」「読点・段落・やわらかさ」をまとめ直した）
いちばんの基準は「美容師がお客様に実際に説明するなら、どう話すか？」。
文字数・句読点・語尾の回数を合わせるために、不自然な日本語にしない。迷ったら読みやすさを優先する。

### 口調
- カット中やシャンプー台で、お客様に話しかけるような柔らかい口調。です・ます調を土台に、自然に出る「〜なんですよ」「〜ですよね」「〜かもしれません」を混ぜる
- 丁寧すぎず、馴れ馴れしすぎない。タメ口・ネットスラングは使わない
- 説明調を続けない。「〜してください」「〜が大切です」「〜というわけではありません」「〜とされています」が2文以上続いたら、話し言葉に言いかえる
  - 「38度前後のお湯を使ってください」→「お湯は38度くらいがちょうどいいですよ」
  - 「すすぎが大切です」→「実は、すすぎのほうが時間をかけてほしいところなんです」
  - 注意事項（受診の目安・商品の効果の打ち消し）では「〜してください」「〜わけではありません」をそのまま使ってよい。正確さが優先
- 硬い言葉は日常の言葉に（「重要」→「大事」、「推奨」→「おすすめ」、「〜となります」→「〜になります」、「行う」→「する」、「傾向があります」→「〜しがちです」）
- 専門用語（キューティクル・角質・皮脂など）は、ひと言で分かる説明を添える
- 「！」「？」は気持ちが動くところ・本当に聞きたいところだけ。数を合わせるために付けない
- 表記：「モノ」「キレイ」「カラダ」「是非」「ツヤっと」「サラッと」

### 文の切り方
- 短くするためだけに、不自然なところで文を切らない。ひと続きの話は1文で言い切る
  - ×「理由はシンプル。空気の乾燥です。」→ ○「いちばん大きいのは、空気の乾燥なんです。」
  - ×「【すすぎは洗う時間の倍】」の後に「です。」だけの段落 → ○ 枠の前後の文で意味が通るようにする
  - ×「結論、洗い方を見直してからで遅くない。」→ ○「まずは洗い方を見直してからでも遅くないですよ。」
- 体言止めや短い言い切りは、場面を見せる・間を作るところだけ。続けて多用しない
- 長い文は、内容の区切りで「。」にする。「〜が、」「〜ので、」で何度もつなげない
- 1文は40字くらいまでが目安（チェックは50字超でNG）

### 読点
- 読点「、」は少なめ。1文に0〜1個が基本。読みにくくなるなら2個まで使ってよい
- 「ただ、」「でも、」「実は、」など話し始めの読点はOK

### 改行と空行（スマホ）
- 1〜2文で1段落。段落の間は空行（rules/html_style.md「基本」）
- 話題が変わったら段落を分ける。ただし、つながっている2文を別の段落に引き離さない

### 重複を減らす
- 同じ内容・同じ言葉を繰り返さない。導入で示した3つと、まとめの3つは同じ文にせず、まとめは「やること」の形で言い直す
- まとめで本文の説明をもう一度くり返さない。「この3つ。」のような確認の一言は付けない
- 内容が重なる小見出しは1つにまとめる（例：「やりがちな洗い方」と「正しい洗い方」が同じ話なら1つに）。よくある質問は本文に無いことだけ

### 不自然な言い回しを避ける
- 枠の中も普通の日本語にする。「頭皮は、今日からやさしくいたわれます。」のような、主語と動詞がかみ合わない文・翻訳調の文は書かない
- 「〜を。」「〜で。」のような言いさしの文、決めゼリフのような一言を多用しない
- 書いたら声に出して読み、美容師がお客様に言わない言い方は直す

### 商品の紹介
- 売り込みにしない。「こういう悩みなら、こういう方法もありますよ」と、解決方法のひとつとして紹介する
- 先に悩みと家でできるケアを説明し、その流れで「〜が気になる方には、〜も合いやすいです」と添える
- 効果を約束しない。登録内容（facts・fits・not_claims）の範囲だけ。not_claims は打ち消しとして必ず書く

### 正確さ
- 専門的な内容・注意事項は正確に。根拠のない断定をしない（「一般的に」「目安」「〜こともあります」「人によって違います」を添える）
- 頭皮の病気・急な抜け毛が疑われる場合は皮膚科をすすめる

### 自動チェック（check_post.py）との関係
- チェックは単調さ・長すぎる文・読点の多さを見つけるための目安。OK にするためだけに文を不自然に切ったり、語尾を無理に変えたりしない
- NG が出たら、意味と自然さを保ったまま直す

## 使わない言葉・書かないこと
- 「僕は」「思います」「候補」は使わない（言い切るか、「〜がおすすめです」「〜しやすくなります」にする）
- 「先日お客様からこんな質問がありました」は使わない。導入は「こんなご相談をよくいただきます。」＋「よくあるご相談」の吹き出し（一般的な悩みとして書く）
- 実際のお客様の話・会話・施術例・数字の実績を作らない
- 「実際に使って」「使ってみて驚いた」など、本人の使用感を作らない
- 「必ず治る」「白髪が減る」「髪が生える」など、根拠のない効果や医療的な表現を書かない。頭皮の病気・急な抜け毛が疑われる場合は皮膚科をすすめる
- 商品の価格・成分・効能は、登録内容（data/affiliate_links.json の facts・fits・not_claims）で確認できる範囲だけ。価格は書かない（「○円」と書かない。「10円玉大」などの例えも使わない）
- 広告表示（「PR」「広告」「アフィリエイト広告を含みます」など）は書かない。投稿時に本人がアメブロで確認する
- 購入への誘導文（「Amazonで見る」「商品ページを見る」「価格・詳細を見る」「こちらから購入」など）は書かない

## 記事の構成（この順番）
1. プロフィール・提案スタイル（rules/profile.json の self_intro・proposal_lines。部品そのまま）
2. 大見出し（タイトルと同じ）
3. 導入
   - 「こんなご相談をよくいただきます。」＋吹き出し（2〜3文）
   - 共感（「これ、〜ですよね。」＋場面の短文3つ）→ 心の声を黄色枠で
   - 「でも、まず知っていただきたいことがあります。」→ 基本の事実（緑枠）。決まり文句は自然に流れるときだけ使う
   - 大切なこと3つをリスト枠で先に示す
   - 「そんなわけで今回、〜について解説します。」
4. ①〜⑥前後の小見出し（h3）。内容が重なる見出しは1つにまとめ、増やしすぎない
   - 原因（2〜4つ）→ 対策・具体的なヘアケア方法（家でできる手順。順番・回数・時間など具体的に）→ 注意点（やりがちな間違い）
   - 商品紹介は悩みに合う登録商品があるときだけ。1〜3商品。無理に入れない。紹介する h3 は「○○が気になるなら〈商品名〉」のように悩みと結びつける
   - 商品は「商品名」部品で名前だけを置き、前後の本文で特徴・向いている髪質・使い方を自然に説明する（リンクは本人が投稿時に Ameba Pick で付ける）
   - 疑問形の小見出し（「〜しても良い？」）を1〜2個入れる
5. 比較表（比べると分かりやすいテーマのときだけ）
6. よくある質問（h3「よくある質問」＋Q&A 3〜5問。本文の小見出しと同じ質問は入れない）
7. まとめ（h3「まとめ｜〜」。3つのやることをリストで → 商品名（必要なときだけ）→ 自然な前向きの一言 →「是非参考にしてみてください！」。本文のくり返し・「この3つ。」は書かない）
8. LINE（2行目をテーマに合わせる）・店舗・Instagram（部品そのまま）

## タイトル
- 型：「〈悩み・疑問〉？〈原因・理由〉と〈数字〉つの〈対策・方法・選び方〉」
- 検索される言葉（例：「ボブ 広がる 40代」）を前半に入れる。25〜45字
- 【】で年代や悩みを示すのは可。煽り（「絶対」「9割が知らない」など）は使わない
- 「3つの」が続きすぎないよう、直近3本と同じ数字・同じ語尾（原因と対策／方法）が重なったら変える

## 長さ
- 本文 3500〜4500字が目安（参考記事は約3,500〜4,200字。チェックは 2500〜7000字）
