# HTML 装飾のルール

参考記事（samples/html/ 02〜06）の装飾に合わせたもの。値の一覧は rules/style_analysis.md の「4. HTML装飾」。

## 基本
- 部品は templates/components.html のものだけを使う。部品の style は変えない（文字だけ差し替える）
- インラインCSSのみ。`<style>`・`class`・`id`・`<script>`・`<iframe>`・`position`・`flex`・`grid` は使わない
- 記事全体を「全体の包み」の div で1回だけ包む。本文の `<p>` には style を付けない（包みの 16px・行間1.9 を使う）
- 1文ごとに `<p>` を分ける。`<p><br></p>` の空行は入れない（余白は部品の margin で取る）
- 画像は rules/profile.json の allowed_images（顔写真・LINEボタン）だけ。新しい画像URLを作らない

## 並び順（記事の上から）
1. プロフィール → 提案スタイル
2. 大見出し h2（タイトルと同じ文）
3. 導入（相談の吹き出し → 心の声の黄色枠 → 結論の3つのリスト）
4. 小見出し h3 ①〜⑦前後（原因・対策・商品・使い方・疑問）
5. 比較表（比べると分かりやすいテーマのときだけ）
6. よくある質問 h3 ＋ Q&A 3〜5問
7. まとめ h3（3つのリスト → 商品名 → 緑の強調 →「是非参考にしてみてください！」）
8. LINE → 店舗 → Instagram

広告表示（PR・広告）は入れない。本人が投稿時にアメブロで必要な表示を確認する

## 枠の使い分け
- 黄の強調：読者の心の声「〜？」、判断のポイント
- 緑の強調：結論・いちばん伝えたいこと
- 青の強調：「それは」の後の【キーワード】
- 赤：「ただし〜」の打ち消し、受診の目安、やりがちなNG
- リスト枠：原因・手順・まとめの3つ（`<strong>`＋`<br>`）
- 灰の流れ枠：工程や順番
- 強調枠は1つの h3 に1〜3個。枠が続きすぎないよう、間に本文を2行以上入れる
- 記事全体で強調・リスト枠は15〜25個が目安

## 商品紹介
- 「商品名」部品（青枠・太字）に data/affiliate_links.json の display_name だけを入れる。リンク・販売先・ボタン・「PR」・価格は入れない
- アフィリエイトURL（Ameba Pick の d.odsyms15.com など）は HTML に一切入れない。本人が投稿時に商品名を確認して Ameba Pick のリンクを設定する
- 「Amazonで見る」「商品ページを見る」「価格・詳細を見る」などの購入誘導文・ボタンは入れない
- 1商品につき2〜3回まで（紹介する h3 で1回、まとめで1回が基本）

## スマホ表示
- 比較表は3列まで。セルの文は短く（1セル20字前後）
- 横幅を固定する width（px）は使わない。画像は max-width:100%
